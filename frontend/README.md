# Frontend: Akkadian Translation Interface

Интерфейс для работы с моделью машинного перевода. Реализован на ванильном JavaScript и HTML/CSS. Взаимодействует с бэкенд-сервером через WebSocket для получения перевода в реальном времени.

## Структура

* `index.html` — разметка интерфейса.
* `app.js` — логика взаимодействия (дебаунс ввода, работа с WebSocket).
* `styles.css` — стили оформления (в репозитории присутствует, но не был предоставлен в коде).
* `Dockerfile` и `nginx.conf` — конфигурация для сборки и развертывания через Nginx.

## Логика работы

* **Дебаунс (Debounce)**: Запрос на сервер отправляется через 650 мс после прекращения ввода текста, чтобы не перегружать API лишними запросами.
* **WebSocket**: При каждом новом запросе текущее соединение прерывается (`abortActiveRequest`), и открывается новое.
* **Реактивность**: Перевод отображается в блоке `#target` по мере поступления данных.

## Использование с Docker

### Сборка образа

```bash
docker build -t akkadian-frontend .

```

### Запуск контейнера

```bash
docker run -d -p 8000:80 --name akkadian-ui akkadian-frontend

```

После этого приложение будет доступно по адресу `http://localhost:8000`.

## Настройка

В файле `app.js` заданы параметры подключения:

* `port = 8080` — порт, на котором ожидает соединения бэкенд-сервер.
